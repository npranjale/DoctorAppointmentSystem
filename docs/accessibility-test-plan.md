# Accessibility test plan

1. Navigate the entire site using Tab, Shift+Tab, Enter, Space and Escape.
2. Confirm skip link appears on focus and moves focus to the main region.
3. Inspect labels, instructions, validation errors and announcements using JAWS.
4. Run axe DevTools on Home, Doctors, Details, Login, Register, Appointment form and list.
5. Verify text and controls meet WCAG 2.1 AA contrast; test browser zoom at 200% and 400%.
6. Test narrow viewport reflow and ensure no loss of content or functionality.
7. Confirm meaningful alt text and decorative imagery treatment.
8. Manually verify accessible names, focus order, error identification and status messages.
